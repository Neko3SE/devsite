# 無駄技研。国際化完全版

日本語・英語・フランス語・韓国語・スペイン語・繁體中文・简体中文・ヒンディー語の切替と文化研究記録を追加した、PC／Android／iPhone対応の分割版です。

## 起動方法

`mudagiken.html` をブラウザで開いてください。

- ES Modules、外部API、外部ライブラリは使用していません。
- Webサーバーを使わないローカルファイル起動にも対応しています。
- iPhoneでは、端末のサイレント設定により音が出ない場合があります。

## ファイル構成

- `mudagiken.html` — トップページとゲーム表示領域
- `mudagiken.css` — トップページ・文化説明・全ゲーム共通CSS
- `mudagiken_common.js` — 共通UI、言語切替、BGM、効果音、演出、画面切替
- `i18n/i18n.js` — 国際化共通処理
- `i18n/ja.js` — 日本語ファイル
- `i18n/en.js` — 英語ファイル
- `i18n/fr.js` — フランス語ファイル
- `i18n/ko.js` — 韓国語ファイル
- `i18n/es.js` — スペイン語ファイル
- `i18n/zh-Hant.js` — 繁體中文ファイル
- `i18n/zh-CN.js` — 简体中文ファイル
- `i18n/hi.js` — ヒンディー語ファイル
- `games/game001_deploy.js` ～ `games/game010_shrine.js` — 各ゲーム固有ロジック
- `docs/` — 適用した国際化仕様

## 言語切替

- トップページとゲーム画面の言語セレクターから切り替えられます。
- 選択言語は保存され、再訪時に復元されます。
- ゲーム中に切り替えても、スコア、HP、タイマー、コンボ、ステージ、進行度は維持されます。
- 言語を追加する場合は、`i18n/ja.js` または `i18n/en.js` と同じ構造の言語ファイルを登録します。

## 文化説明

ゲームカードを選択した直後、ゲーム開始前に表示されます。再挑戦時は文化説明を省略して直接ゲームを再開します。
