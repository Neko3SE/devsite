# AI駆動型非生産的Web技術研究所。

Neko3SE LAB experimental browser content.

**Live Site / 実際に使う:** https://neko3se.com/mudagiken/

## Overview / 概要

生成AIを実用的なツールの制作だけでなく、「くだらないアイデアを本気で実装する」ために使ったら、どこまで遊べるWebコンテンツを作れるのか。

**English**  
What happens when generative AI is used not only for practical tools, but to seriously implement deliberately silly ideas?

## Features / 主な機能

- 10 browser mini-games in one content page
- PC and smartphone-oriented interaction
- Sound effects, animation and visual effects
- Multilingual UI using separate language resources

## How It Works / 仕組み

主要なゲーム処理・演出・多言語表示をブラウザ上で実行しています。

**English**  
Game logic, effects and multilingual presentation run in the browser.

## Technology / 使用技術

HTML5, CSS, JAVASCRIPT, WEB AUDIO, RESPONSIVE DESIGN, INTERNATIONALIZATION

## Environment / 動作環境

ブラウザ上で動作するコンテンツです。PC・Android・iPhoneを含む実機検証を行っていますが、端末・OS・ブラウザの組み合わせすべてを保証するものではありません。マイクや音声を利用するコンテンツでは、ブラウザ権限や端末設定も動作に影響します。

**English**  
This content runs in a web browser and has been tested on real devices including PC, Android and iPhone environments. This does not guarantee every device, OS and browser combination. For microphone/audio content, browser permissions and device settings can also affect behavior.

## Known Limitations / 既知の制約

- Performance and audio behavior can vary by device and browser.
- Mobile devices may require lighter rendering than desktop environments.
- Device mute/silent settings can affect audible output independently of the page logic.
