Android WAV Filename Diagnostic

Androidブラウザが Blob のMIME typeと download 属性から保存名をどう決定するかを切り分ける診断ページです。音声は440 Hz・約1秒のテストトーンです。

File / Web Share comparison

対応端末ではBlob URLを使わず、名前付き File をOS共有機能へ渡します。共有画面でファイル名を確認してください。

Diagnostic log

判定の目安

Aだけ異常 → audio/wav のMIME処理を疑います。
A/B異常・C正常 → Androidの音声MIME→拡張子/名前推測処理を疑います。
A/B/Cすべて異常・D正常 → Blob URL + download属性からAndroid Download Managerへの名前引継ぎを疑います。
A/B/C/Dすべて異常 → ブラウザからOS保存/共有層まで含む実装依存を疑います。
