WEB API × DEVICE CAPABILITY

01 / WHY

なぜ作った？

Webアプリでは、同じコードでもiPhone・Android・PC、さらにブラウザによって利用できる端末機能が異なります。その差を実機で確認するための基礎研究ツールです。

02 / EXPERIMENT

何を試す？

端末情報、表示環境、CPU・メモリ、GPU、カメラ、マイク、センサー、接続系API、ストレージ、WebXRなどを、APIの存在確認だけでなく可能な範囲で実アクセスまで試します。

03 / FINDINGS

何が分かる？

取得できない情報も結果です。NOT SUPPORTED、NOT EXPOSED、PERMISSION DENIED、HARDWARE NOT FOUNDなどを区別し、ブラウザから見える端末能力の境界を観察します。
