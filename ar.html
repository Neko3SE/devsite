PHASE 4.20 TEST PROCEDURE

  1. まずカード形状ターゲットを平らで動かない面に固定します。反射が強いカードより、角が明瞭なマットなターゲットが扱いやすいです。
  2. START AR後、中央＋を TL → TR → BR → BL の各隅へ順に合わせ、各回 CARD ボタンを押します。A/B測距は行わなくても構いません。
  3. 4点取得すると、幅・高さ・対角線、各辺の尺度比、単一scaleを仮定した残差、角度、4点の平面残差を自動計算します。
  4. 同時に各点のDepth 3Dと plane / point / mesh の位置差をログへ記録します。Depthも補正には使いません。
  5. 1回目はターゲットを約0.5〜1 mから取得してください。完了後、必要ならRESET CARD CALで同じ条件をもう1回だけ取得します。
  6. ログの CARD CAL POINT と CARD CAL SUMMARY を共有してください。20 / 50 / 100 cm sweepは比較用として残していますが、Phase 4.20の主試験は4隅キャリブレーションです。

CONTROLS

Phase 4.20でも正式な単発距離値はimmutable Hit-Hitのままです。MAP integrityは座標再配置を検出する単発測定ゲートとして維持します。Depth 3×3 medianから復元したA-B距離との差 |Hit-Hit − DepthMedian| は、<5 mm = AGREE、5〜15 mm = WARN、15 mm以上 = DIVERGEDとして記録しますが、正式距離の補正・拒否には使いません。 従来のHit-Hitコンセンサスは「再現性」の診断として残します。既知寸法に対する正しさ（accuracy）とは分離して扱います。近接幅は暫定 max(5 mm, クラスタ中央値の1%)、必要メンバー数はその時点の有効試行数に対する厳密多数派です。 HIT ENTITY SNAPSHOT、CENTER ALIGN CHECK、MAP integrity、Hit Test直前0.3秒のSTABLE / MOVING warning-onlyは継続します。
