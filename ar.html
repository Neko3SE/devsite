FORMAL HIT-HIT ACCURACY / REFERENCE TARGET

Phase 4.40では、外部の物理基準で作った 50 / 100 / 150 cm を各3回だけ測定し、正式な immutable plane Hit-Hit の絶対誤差と再現性を評価します。値が悪いことを理由に有効サンプルを捨てたり追加測定したりせず、各距離の最初の有効3回をすべて統計へ含めます。MAP INVALID / reference-space reset など既存の安全ゲートで無効になった測定だけが自動除外されます。Repeatability cluster、Depth、Anchorは診断専用で、正式Hit-Hit値の補正・採否には使用しません。

PHASE 4.40 REV.3 — INDEPENDENT ACCURACY PROCEDURE

  1. カード校正は使用しません。外部の巻尺・スケール等で、同一の平坦かつテクスチャのある面に A/B の中心間距離 50.0 cm、100.0 cm、150.0 cm の基準を用意します。アプリの値を見て基準位置を調整しないでください。
  2. START AR後、Tracking が ACTIVE になり、Hitが安定するまで待ちます。初回ターゲットは50 cmです。
  3. RESET MEASURE後、基準点Aの中心を中央照準＋へ合わせます。`SURFACE DETECTED` かつ `AIM QUALITY: GOOD`（または NEAR RANGE）になると CAPTURE POINT A が有効になるので押します。映像タップでは取得しません。A確定後は同じ方法で基準点Bへ合わせ、CAPTURE POINT B を押します。正式値はその2つのimmutable plane Hit位置だけから確定します。
  4. COMMITTED MEASUREMENT / ACCURACY SAMPLE が記録されたら1回完了です。誤差が大きくても有効サンプルは捨てません。MAP INVALIDやreference-space resetで自動的にINVALIDとなった試行だけを数え直します。
  5. RESET MEASUREして同じ50 cmを合計3回測定します。3回目の有効値が記録されると次ターゲットが予約され、次のRESETで100 cmへ自動切替します。
  6. 100 cmを3回、続いて150 cmを3回、同じ手順で測定します。合計9個の有効Hit-Hit値を取得します。
  7. Repeatability cluster、Anchor drift、Depth-center / Depth-medianは診断として記録しますが、正式距離の補正・拒否・サンプル選別には使いません。
  8. 150 cmの3回目まで完了し、ログに ACCURACY SWEEP COMPLETE が出たらEND ARを押し、LOGを共有してください。

A4 PLANAR TARGET / EDGE CALIBRATION — LEGACY DIAGNOSTIC

Phase 4.40の独立精度評価では使用しない旧診断機能です。必要な回帰確認時のみ使用します。Phase 4.30 Rev.16由来のA4用紙上に作った150.00 × 237.00 mmの長方形を使用します。Raw Cameraの同一フレームを固定し、TOP → RIGHT → BOTTOM → LEFT の各直線部分を5点ずつ大まかにタップします。5点は測定点そのものではなく黒線探索の初期位置として扱い、Frozen画像の輝度から各タップ近傍の暗い細線中心へ法線方向に自動スナップしてから2D直線QCと4-of-5外れ値判定を行います。姿勢推定では仮想四隅を作らず、辺上位置uも自由変数にせず、既知150 × 237 mm剛体長方形をFrozen画像へ投影した4本の線と、残った16〜20個のスナップ済み画像点との垂直ピクセル距離を直接最小化して6DOF姿勢を解きます。Hit Test / Depthは姿勢推定に使用せず、補正係数も適用しません。全辺の画像スナップGOOD・使用点RMS 2.5px以下・span 50px以上・外れ値除去時の有効span保持率65%以上を必須とし、姿勢解の各辺coverage 50%以上かつ最終fit quality=GOODの場合だけ同一Frozen比較の正式基準へ保存します。Tracking ACTIVE時は従来どおりLOCAL参照空間のRaw Camera幾何でFREEZEします。LOCAL trackingがLOST/UNSTABLEでもviewer参照空間のRaw CameraとXRView幾何が新鮮なら、そのフレームをVIEWER-ONLYとして単発FREEZEできます。VIEWER-ONLY結果はFrozen時点のviewer参照空間でのみ解釈し、world/local座標のフレーム間比較には使用しません。LOCALもVIEWERも新鮮でない場合だけFREEZE要求を予約し、どちらかの新しい有効フレームが到着した最初のタイミングで自動FREEZEします。予約中に同じボタンを押すとキャンセルできます。 Rev.16ではさらに、LMマルチスタートのsupported seed比率と選択解周辺のpose cluster比率をhard gate化し、seed consensusを通過した解でも同一Frozen画像で2回連続の姿勢一致を確認してからCONFIRMEDとします。CONFIRMED後は、姿勢推定に使用していないA4平面上の独立した十字マークA〜Dを1回ずつ取得します。タップはseedとしてのみ扱い、Frozen画像から投影A4軸に沿う暗い十字の交点へ自動スナップします。同じ4中心からA-B / B-C / C-D = 50 mm、A-C / B-D = 100 mm、A-D = 150 mmの6距離を一括算出し、確定平面への3D ray交点距離と、確定した投影剛体矩形から逆変換する2D homography距離を並記します。補正値は適用せず、画像位置依存の偏りと3D/2D経路の整合性を診断します。A〜Dのsnapには補正を伴わないsanity guardを追加し、既存点との20 mm未満の重複候補またはカード座標で5 mmを超える横方向spanを検出した場合は、その点だけ取り直します。 Rev.16では、4辺がGOODになった直後に投影矩形の縦横比を確認し、150 × 237 mmターゲットが90°横向きと強く判定できる場合は6DOF Solverへ進まず、90°回転してREFREEZEするよう案内します（180°反転は許可）。 90°不一致を検出したFrozen画像ではRESTART 20 TAPSを無効化し、再タップではなく新しいREFREEZEだけを許可します。またRIGHT / LEFTの画像スナップが通常18px探索で距離不足または境界到達により失敗した場合だけ、同じ5 seedを28pxまで自動再探索してから再タップを要求します。コントラスト・角度・直線QC・coverage・Solver consensus・同一Frozen repeatの合格条件は緩和しません。

LEGACY CARD SOLVER PROCEDURE — NOT USED IN PHASE 4.40

  1. A4用紙の四辺から30 mm内側に引いた150.00 × 237.00 mm長方形を平らな面へ固定します。
  2. START AR後、長方形全体をRaw Camera中央領域へ入れてFREEZEを押します。現在のライブ表示がLOCALならLOCAL幾何、LOCAL LOST/UNSTABLEでVIEWER_FALLBACKが新鮮ならVIEWER-ONLY幾何でその場でFREEZEします。どちらも新鮮でない場合だけQUEUE FREEZEとして予約され、次の新鮮なLOCALまたはVIEWERフレームで自動FREEZEします。予約中はCANCEL FREEZEで取り消せます。以後のタップは同じFrozen画像を使います。
  3. TOP → RIGHT → BOTTOM → LEFTを各5点、角を避けながら黒線の近くへできるだけ広く分散してタップします。タップは初期位置で、各5点入力後にFrozen画像の暗線中心へ自動スナップします。
  4. 各辺は画像スナップGOODに加えて、使用点RMS 2.5px以下・span 50px以上を必須とします。スナップは初期直線の法線方向±18pxを探索し、周囲との輝度コントラストで黒線中心を選びます。4-of-5で1点を外れ値除去した場合も、残る4点のRMS 2.5px以下かつ沿辺span保持率65%以上が必要です。
  5. 4辺すべてGOODになった場合だけ、150 × 237 mm剛体長方形をFrozen画像へ投影した4辺と16〜20画像点の垂直距離を直接最小化します。仮想四隅と独立した辺上u変数は使いません。
  6. 各投影辺のcoverageと物理辺区間uを別々に確認します。uが[0,1]を外れた場合は実際にoutsideを発生させた辺を最優先で再タップし、同じ辺で2回再タップしてもoutsideが続く場合は角度／フレーミング限界としてREFREEZEを要求します。outsideがなくcoverageだけ50%未満なら、最もcoverageの低い辺だけを消去します。他の3辺は保持されます。
  7. 全辺の画像スナップGOOD＋入力GOOD＋coverage gate PASS＋最終fit quality=GOODのときだけ診断結果を確定し、同一Frozen比較の基準へ保存します。RESTART 20 TAPSでは同じFrozen画像の確定結果同士だけを比較します。
  8. 撮影画像そのものを変える場合だけLIVE / RETAKE → FREEZE A4 FRAMEを使用します。
  9. ログの CARD EDGE LINE REJECT / CARD EDGE INPUT RETAP REQUIRED / CARD EDGE COVERAGE RETAP REQUIRED / CARD PROJECTED EDGE FIT SUMMARY / CARD SAME-FROZEN REPEAT DELTA を共有してください。

CONTROLS

Phase 4.40 Rev.4でも正式単発距離値はimmutable Hit-Hitのままです。Point BボタンはA-B距離では無効化せず、長い基線を移動中も操作可能にします。Point BのAIM QUALITYは警告専用とし、押下時のcurrent plane Hitだけを必須条件として維持します。カード機能は今回の独立精度評価には使用しません。A4校正を開始するとA/B測距はRESET A4 CALまたはEND ARまでロックします。A4校正は1枚のRaw Camera静止画像を使い、各辺5点を黒線探索の初期位置としてFrozen画像の暗線中心へ自動スナップし、4-of-5外れ値QCした後、既知150 × 237 mm剛体長方形をFrozen画像へ投影した4辺と残った16〜20画像点の垂直距離を直接フィットします。仮想四隅も独立した辺上uも姿勢変数として使いません。LMの収束診断を明示し、全4辺の使用点RMS 2.5px以下、span 50px以上、外れ値除去後のspan保持率65%以上を入力のhard GOOD gateとして要求します。WARN入力はその辺だけ再タップし、全辺GOODになるまで姿勢推定へ進みません。さらに投影後の全辺coverage 50%以上と全サンプルu∈[0,1]を別々に要求します。outside時は実際のoutside辺だけを再タップし、同一辺で2回失敗後はREFREEZEを要求します。coverage不足だけなら最も弱い辺だけ再タップします。同じFrozen画像をRESTART 20 TAPSで繰り返すと、全辺画像スナップGOOD＋入力GOOD＋coverage PASS＋最終fit GOODに加え、supported seed比率50%以上・選択解周辺cluster比率60%以上を要求します。最初の通過解はPROVISIONALとし、次の同一Frozen解がcenter 3 mm以内・normal 3°以内・projected-corner RMS 1.5 px以内かつmax 3 px以内に一致した時だけCONFIRMEDとします。LOCAL LOST時にVIEWER-ONLYでFREEZEした結果はそのFrozen時点のviewer参照空間だけで有効であり、別Frozenとのworld/local位置比較には使用しません。Hit Test / Depthは姿勢推定に使用せず、結果は診断専用で補正係数や絶対精度判定には使用しません。MAP integrity、Depth agreement、Hit entity probeなど従来の距離診断はそのまま維持します。
